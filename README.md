# Car Showroom API

Premium Django REST API backend for a futuristic automotive showroom platform.

## Features

* Car listings management
* Multiple car images
* JWT authentication
* Office information API
* Social media links
* Media upload handling
* Admin dashboard
* RESTful APIs
* CORS support

## Tech Stack

* Django
* Django REST Framework
* Simple JWT
* SQLite
* Python 3.13

## Installation

```bash
git clone https://github.com/Anas-bagdady/car_showroom.git

cd car_showroom

pip install -r requirements.txt

python manage.py migrate

python manage.py runserver
```

## API Authentication

JWT Authentication is enabled using:

* `/api/login/`
* `/api/token/refresh/`
